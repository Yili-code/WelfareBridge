# 資料庫規則稽核（2026-11-02）

目的：檢查 974 筆可媒合補助（canonical、非彙整頁、未截止）的規則、金額、期間、狀態是否與原文一致。

## 方法

1. **程式掃描**（`backend/scripts/audit_rules.py`）：數值是否出現在原文、運算子方向、數字是否被誤歸屬（利息、存款）、設籍縣市是否有依據、狀態與截止日是否矛盾。
2. **AI 對照原文複核**（`backend/scripts/audit_rules_llm.py`，gemma4:26b，974 筆，約 80 分鐘）：每個疑點必須附原文引句，引句不在原文就丟棄（共丟棄 179 項）。
3. **人工抽樣驗證**：把影響媒合最大的疑點對回原文確認。
4. **修正**（`backend/scripts/fix_known_rule_errors.py`）：只修確認過、有明確模式的錯誤，被改規則的完整內容存在 `docs/audit/known_fixes.json`，可還原。

## 已修正（19 條規則）

| 類型 | 條數 | 說明 |
| --- | ---: | --- |
| `age_after_18` | 7 | 「兒童及少年未來教育與發展帳戶」把「年滿 18 歲後可提領」讀成申請人必須 ≥ 18 歲，未成年的對象被排除 |
| `stateless_excl` | 10 | 「無國籍或未取得居留…」是受益對象之一，被當成排除條件 |
| `inferred_city` | 1 | 原文寫「無需設籍」，卻有依機關推定的設籍縣市（急難紓困） |
| `income_interest` | 1 | 弱勢助學家庭年所得上限由 2 萬（利息所得上限）改為 70 萬 |

另外修了抽取器兩個根本原因：「家庭年所得 70 萬以下」沒寫「元」會被跳過；大數字顯示成 `6.5e+06`（資料庫 43 筆已更正）。

## 還沒處理

- AND／OR 與角色錯誤類（約 900 項）需要人看過 CSV，確認是真錯誤後再決定修法。
- 條文是在描述「父母」或「子女」的條件，卻掛在申請人屬性上（例如花蓮縣兒童及少年生活扶助的「父母一方身心障礙中度以上」），目前沒有自動規則可處理。
